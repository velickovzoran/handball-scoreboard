Bugs found and fixed

Fixed

Stopping the clock threw away the part of the second already run

Every Stop lost up to 0.99 s, so the match (and suspensions) ran on average about half a second longer than real time per stoppage. With many timeouts and stoppages this adds up to several seconds per match. The clock now remembers the leftover milliseconds and continues from them on the next Start.

Evidence: 8 runs of 0.7 s each (5.67 s in total). Before the fix the clock showed 00:00; after the fix 00:05. Automatic stops still land exactly on 30:00 with nothing left over.

Fixed

Long overlay names were cut off by a few pixels

A 24-character name like ЕУРОФАРМ ПЕЛИСТЕР БИТОЛА still overflowed the red bar at the smallest allowed font. The minimum size was lowered so realistic names always fit.

Evidence: overflow of 4 px before, fits at 10 px after. Normal names like ВАРДАР stay at the full 22 px.

Fixed

Three suspension badges touched the team logo circle

With a team logo shown and all three suspensions running, the outer badge sat right against the circle. The badges are now slightly more compact.

Evidence: gap between badges and logo went from 0 px to 21 px on both sides.

Fixed

Small clean-ups

Removed the browser's favicon.ico 404 error on both pages, fixed a 0.01 px rounding overshoot of the TV board on ultra-wide screens, and made Start safe if an old cached copy of common.js is loaded next to a newer index.js.

Not verified

Check once

Opening the files straight from the folder (file://)

All tests ran through a local server because the test browser cannot run pages from disk. The code uses nothing that needs a server, so it should behave the same. Before the first match, open both files in Chrome or Edge by double-clicking, press +1 and Start, and confirm the TV follows.

Known limitations

These are not bugs, but they are useful to know on match day.

Browser

Use Chrome or Edge, and keep only one Control Panel open

Firefox does not share saved data between files opened from a folder, so the TV would stay empty. Two open Control Panels would overwrite each other's data.

Reset

The Reset dialog pauses screen updates while it is open

While “Дали сте сигурни…” is on screen the overlay and TV do not update. If you cancel, the clock jumps to the correct time straight away, so no time is lost.

Clock

Min+ across 30:00 skips the half-time stop

As the spec requires, manual changes never trigger automatic stops. If you press Min+ at 29:30 while running, the clock goes to 30:30 and will not stop at half time.

Suspensions

A suspension pushed back to exactly 02:00 is treated as “armed”

After Sec−/Min− brings a running suspension back to 02:00, further Min/Sec presses leave it alone. It still counts down normally when the clock runs.

Overlay

Keep overlay names short

Names up to about 14 characters show at full size. Longer names shrink, and the 24-character maximum ends up around 10 px, which is hard to read on a stream.

Reset

Reset also removes both team logos

For back-to-back matches with the same team, upload its logo again after Reset.

Refresh

A Control Panel left “running” and closed catches up when reopened

If the page is closed while the clock runs and opened again later, the clock adds the missed time and stops at the next automatic stop. Press Stop before closing the page.

Before the first live match

  1. Double-click index.html, press Отвори Телевизор, drag that window to the arena TV and double-click it for full screen.
  2. Enter short and full team names, upload both logos, and check the stream crop in OBS/vMix (green area is 760 × 160 px, top-left of the page).
  3. Press Start for a few seconds, add a goal and arm a suspension, and watch the TV and overlay follow. Then press Ресетирај сè.
